# Pet Disease Detection AI

An AI-powered application for detecting common skin diseases in dogs and cats using EfficientNet-B0.

## Diseases Detected

- Fungal Infection in Dog
- Hot Spots in Dog
- Mange in Dog
- Ringworm in Cat
- Skin Allergy in Dog

Built using:

- PyTorch
- EfficientNet-B0
- Gradio
- Hugging Face Spaces
